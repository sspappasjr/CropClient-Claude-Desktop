◎ Step 1 — Install Ollama
Download the Ollama server, pull your first model, and verify it's running
A Install Ollama
Ollama installs as a system service and starts automatically on port 11434. No configuration needed.
  • Go to ollama.com → click Download
  • macOS: open the .dmg, drag Ollama to Applications, launch from Spotlight
  • Windows: run OllamaSetup.exe, follow the installer prompts
  • Linux: run the one-line install script below
  • After install, Ollama starts automatically at localhost:11434
Linux install
curl -fsSL https://ollama.com/install.sh | sh
Verify install
ollama --version
B Pull Your First Model
Use ollama pull to download a model. It downloads once and caches it locally.
Recommended starter — coding model
ollama pull qwen2.5-coder
General purpose
ollama pull llama3.2
Small / fast (runs on CPU)
ollama pull phi3
Browse all models 
ollama list                    # show what you have downloaded
# Browse all at: https://ollama.com/library
C Start & Verify Ollama
Ollama starts automatically after install. If it's stopped, start it manually. Then use the live check below to confirm it responds.
Start manually (if stopped)
ollama serve
List downloaded models
ollama list
—
Terminal check (curl) 
curl -s http://localhost:11434
# Expected: "Ollama is running"

curl -s http://localhost:11434/api/tags
# Returns your downloaded models as JSON
✦ Step 2 — OpenCode Desktop
Install OpenCode, connect it to Ollama, add models and vendor API keys
DInstall OpenCode Desktop
OpenCode Desktop is an AI-native coding environment. It natively supports Ollama — no extra plugins needed.
  • Go to opencode.ai → Download for your OS
  • macOS: open the .dmg, drag to Applications
  • Windows: run the .exe installer
  • Launch OpenCode — onboarding wizard opens on first run
EConnect OpenCode to Ollama
Add Ollama as a provider. OpenCode auto-discovers models running at localhost:11434.
  • OpenCode → Settings (gear icon or ⌘,)
  • Go to Providers → + Add Provider → Ollama
  • Base URL is pre-filled: http://localhost:11434
  • Click Test Connection → your model list loads
  • Select a default model → Save
FAdd More Ollama Models via OpenCode
OpenCode can pull Ollama models for you — it runs ollama pull in the background.
  • Settings → Providers → Ollama → Browse Models
  • Find a model → click Pull
  • Model appears in the picker when download completes
GAdd Vendor API Models (Anthropic, OpenAI)
Connect cloud providers alongside your local Ollama models. Each requires an API key.
  • Settings → Providers → + Add Provider → Anthropic (or OpenAI)
  • Paste your API key from console.anthropic.com or platform.openai.com
  • Click Test Connection → model list loads
  • Save — cloud models now appear alongside your local ones
API keys are stored locally in OpenCode's config — they're never sent anywhere except the provider's own API.
HSwitch Active Model
Switch between Ollama and vendor models mid-conversation.
  • Press ⌘K (Mac) or Ctrl+K (Win) → Command Palette
  • Type Switch Model — or click the model name in the status bar
  • Pick from the list: Ollama (local), Anthropic, OpenAI
  • Set a permanent default in Settings → Providers

Minimal server example 
// mcpserver.js
const express = require('express');
const app = express();
app.get('/ping',  (req, res) => res.json({ ok: true, ts: Date.now() }));
app.get('/tools', (req, res) => res.json({ tools: [] }));
app.listen(3101, () => console.log('mcpserver listening on 3101'));
