const express = require('express');
const app = express();
app.get('/ping', (req, res) => res.json({ ok: true, ts: Date.now() }));

app.listen(3101, () => console.log('mcpserver listening on 3101'));
◎ Ollama Setup
Chapter 1 — Install, pull a model, and verify the server
A Install Ollama
Download and run the Ollama installer for your operating system. Ollama installs as a system service and starts automatically.
  • Go to ollama.com and click Download
  • macOS: run the .dmg, drag Ollama to Applications
  • Windows: run OllamaSetup.exe, follow installer
  • Linux: curl -fsSL https://ollama.com/install.sh | sh
  • After install, Ollama runs on localhost:11434 automatically
Verify install — terminal commands 
ollama --version           # prints version number
curl localhost:11434       # should return "Ollama is running"
B Pull a Model
Use ollama pull to download a model locally. The download runs once and caches the model on disk.
Recommended starter model
ollama pull qwen2.5-coder
Other good choices
ollama pull llama3.2
ollama pull codellama
See all available models 
ollama list              # models you have downloaded
# Browse all at: https://ollama.com/library
C Start & Verify Ollama
Ollama starts automatically after install. If it's not running, start it manually. Then verify with a live ping below.
Start Ollama server (if not auto-started)
ollama serve
List downloaded models
ollama list
—
Terminal alternative (curl) 
curl -s http://localhost:11434
# Expected: "Ollama is running"

curl -s http://localhost:11434/api/tags | python3 -m json.tool
# Lists downloaded models as JSON
✦ OpenCode Desktop
Chapter 2 — Install, connect to Ollama, add models, and switch providers
D Install OpenCode Desktop
OpenCode Desktop is an AI-native coding environment that connects to local Ollama models and cloud API providers from a single interface.
  • Go to opencode.ai and download the installer for your OS
  • macOS: open the .dmg, drag to Applications, launch from Spotlight
  • Windows: run the .exe installer, launch from Start Menu
  • First launch opens onboarding — you can configure providers right away
OpenCode natively supports Ollama as a backend — no extra plugins required.
E Connect OpenCode to Ollama
Add Ollama as a provider in OpenCode's settings. OpenCode auto-discovers models running at localhost:11434.
  • Open OpenCode → Settings (gear icon or ⌘,)
  • Go to Providers → click + Add Provider
  • Select Ollama from the provider list
  • Base URL is pre-filled as http://localhost:11434
  • Click Test Connection — it should return your model list
  • Select your default model and click Save
F Add More Ollama Models via OpenCode
OpenCode lets you browse and pull Ollama models without leaving the app — it runs the ollama pull command in the background.
  • In OpenCode → Settings → Providers → Ollama
  • Click Browse Models to open the Ollama model library
  • Find the model you want and click Pull
  • OpenCode shows download progress; model is ready when bar completes
  • New model appears in your model picker immediately
Pull from terminal instead 
ollama pull mistral          # fast 7B model
ollama pull deepseek-coder   # coding-optimized
ollama pull phi3             # small, runs on CPU
G Add Vendor API Models
Connect Anthropic, OpenAI, or other cloud providers alongside Ollama. Each provider requires an API key from their dashboard.
  • OpenCode → Settings → Providers → + Add Provider
  • Select Anthropic (or OpenAI, Gemini, etc.)
  • Paste your API key from console.anthropic.com or platform.openai.com
  • Click Test Connection — model list loads if the key is valid
  • Click Save — vendor models now appear in your model picker
API keys are stored locally in OpenCode's config — they never leave your machine except in requests to that provider's API.
H Switch Active Model
Switch between Ollama and vendor models in any conversation — each session can use a different model.
  • Press ⌘K (Mac) or Ctrl+K (Win) to open Command Palette
  • Type "Switch Model" or click the model name in the status bar
  • Browse by provider: Ollama (local), Anthropic, OpenAI, etc.
  • Select the model — it takes effect for the current session
  • Set a default in Settings → Providers → choose default model
